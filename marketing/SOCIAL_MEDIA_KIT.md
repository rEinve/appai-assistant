## 5. Hacker News "Show HN" Copy

**Title:** Show HN: AppAI – Autonomous procurement agent with strict budget guardrails

**Body:**
```text
Hey HN,

We've been working on AppAI (appasssistant), an autonomous procurement assistant designed to safely execute recurring purchases and deal watches from natural language instructions.

Most "agentic shopping" experiments fail in practice because giving an LLM unfettered access to payment APIs or browser automation quickly leads to race conditions, hallucinations, or uncontrolled spending.

To make agentic procurement viable, we architected AppAI with explicit zero-trust boundaries:
1. Instruction Dialogue: Conversational intake extracts constraints (cadence, category, budget cap) into an immutable, versioned agreement schema before execution.
2. Dual Permission Modes: `REVIEW_BEFORE_PURCHASE` prepares quotes and requests explicit 1-tap confirmation. `PRE_APPROVED` automates checkout only up to a hard spending ceiling.
3. Durable Worker & Missed-Tick Recovery: Background workers handle timezone transitions, DST shifts, and downtime recovery cleanly without double charges.
4. Payment Separation: We route checkout through established provider gates (e.g., PayPal Orders v2) so sensitive financial credentials never touch LLM contexts.

Frontend is built in React 19 + Tailwind v4; backend runs on Node/TypeScript with PostgreSQL as the transaction authority.

We are opening an early pilot cohort and would love technical feedback on the permission model and execution architecture: https://appasssistant.com/pilot

Happy to answer questions about state synchronization, budget reservation, and agent safety!
```
